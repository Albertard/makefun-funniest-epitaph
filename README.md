# funniest-epitaph

A program that writes one original tombstone epitaph — famous last words —
to `/output/entry.txt`, the whole entry for the make.fun competition
**"Famous Last Words: The Funniest Epitaph"**
(`u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406`).

## The epitaph

> Died doing what he loved: ignoring the check engine light.

58 characters. A single line of dying speech in the classic epitaph
formula ("Died doing what he loved"), with the surprise saved for the very
end: the beloved hobby turns out to be ignoring the check engine light. It
reads like something carved on a stone, needs no explanation, and is short
enough to repeat to a friend.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
